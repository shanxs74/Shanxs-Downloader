# 📥 Shanxs Downloader

أداة مجانية وبسيطة لنظام Windows لتحميل الفيديوهات وقوائم التشغيل (Playlists) من يوتيوب بصيغة **MP4** أو **MP3** بالجودة التي تختارها.

---

## ✨ المميزات

* **مرونة التحميل:** دعم تحميل فيديو مفرد أو قائمة تشغيل كاملة.
* **تعدد الصيغ والجودة:**
  * فيديو **MP4** بجودات مختلفة (من 360p حتى 4K / 2160p).
  * صوت **MP3** بنقاء عالٍ (من 128kbps حتى 320kbps).
* **بدون تثبيت:** تشغيل مباشر بدون الحاجة لترخيص مدير النظام (Admin).
* **تخصيص الواجهة:** إمكانية تغيير صورة الخلفية الخاصة بالبرنامج.

---

## 📁 هيكل المجلد

لكي تعمل الأداة دون مشاكل، يجب أن يحتوي المجلد على العناصر التالية:

```text
